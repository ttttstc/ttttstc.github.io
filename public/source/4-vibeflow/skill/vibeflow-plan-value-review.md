# vibeflow-plan-value-review — CEO 价值评审

## 概述

`vibeflow-plan-value-review` 是 CEO 视角的价值评审 skill。这是整个 VibeFlow 流程中的**唯一关卡** — 价值评审失败 = 项目终止。

---

## 核心理念

> **先问值不值得做，再问怎么做。**

很多项目失败不是因为技术不行，而是因为一开始就问错了问题。

---

## 评审维度

### 1. 价值

- 解决了什么问题？
- 创造了什么价值？
- 对用户有什么实际好处？

### 2. 市场规模

- 目标用户是谁？
- 市场有多大？
- 增长潜力如何？

### 3. 竞争壁垒

- 相比现有方案，你的优势是什么？
- 竞争对手为什么不能快速复制？
- 你有什么护城河？

### 4. 执行风险

- 最大的风险是什么？
- 能承受吗？
- 有缓解措施吗？

### 5. 时机

- 为什么是现在？
- 早做或晚做有什么影响？
- 市场窗口期是什么时候？

### 6. 退出策略

- 如果这个想法不 work，下一步是什么？
- 有 Plan B 吗？
- 什么时候该放弃？

---

## 评审模板

### 问题框定

```
我们要解决的问题是：___________

我们预期带来的改变是：___________
```

### 价值论证

```
直接价值：___________
间接价值：___________
战略价值：___________
衡量指标：___________
```

### 风险评估

```
技术风险：___________
商业风险：___________
缓解措施：___________
```

---

## 评审结果

| 结果 | 行动 |
|------|------|
| **通过** | 继续进入 Requirements 阶段 |
| **失败** | 项目终止，记录 lessons learned |

---

## 为什么是 fail-fast

很多创业公司死于"确认偏误" — 因为太喜欢自己的点子，所以一直往里投资源，直到弹尽粮绝才发现不对。

VibeFlow 的 Plan 阶段就是要在 **投入工程资源之前**，先做一个冷静的评估。

---

## 注意事项

- 这不是技术评审，是价值评审
- 不要讨论"怎么做"，只讨论"值不值得做"
- 如果连自己都说服不了自己这件事值得做，那就不要开始
