关于我

我相信，好的系统
是慢慢「养」出来的。

过去几年我一直在做两件事：把微服务架构和 DevOps / CICD 落到能稳定交付的地步，以及把 AI Agent 从「会写代码」带到「能按工程纪律交付一整轮」。

我搭建了个人 Agent 平台 OpenClaw 的架构实践，也设计了 VibeFlow ——一套让 AI 不再随机开写、而是 Think → Plan → Build → Ship 走完闭环的交付框架。这片实验田，记录的就是这些真实的尝试、翻车与进化。
