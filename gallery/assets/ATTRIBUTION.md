# Studio materials

- `wooden_floor_02`, `beige_wall_001`, and `ash_veneer` textures, plus `desk_lamp_arm_01`, `painted_wooden_chair_02`, `potted_plant_02`, and `ceramic_vase_01` models: [Poly Haven](https://polyhaven.com/), CC0. Textures are 1K JPG diffuse, OpenGL normal, and roughness maps; models use 1K textures.
- `artist-desk.glb`: created for this project in Blender; the editable source remains in the original local workspace.
- `hunyuan-desk.glb`: generated with Tencent Hunyuan3D V3.1 on 2026-11-10, using one free daily generation. `hunyuan-desk-web.glb` is a 2048px WebP derivative for browser delivery; the original remains in the local workspace for further editing.
