**日期**: 2026-03-18

**状态**: 待批准

## 1. 定位

- **纯展示型** - 浏览、搜索、复制 AI 工具系统提示词
- **手工整理 + 自动同步** - 通过 PR 方式合入上游更新
- **多维度分类** - 一级类别菜单 + 二级子分类

## 2. 页面结构

### 2.1 入口流程

```
首页 → 神秘咒语盒（一级菜单）→ 分类页（二级内容）
```

### 2.2 一级分类菜单（首页）

参考 NEWYORKOVER 风格：
- 米白色/浅色背景 (#F9F8F6)
- 大标题 + 简介文字
- 卡片式分类入口，悬停动效
- 三种视图切换（可选）

## 5. 视觉风格（参考 NEWYORKOVER）

### 配色
- 背景: #F9F8F6 (米白)
- 主文字: #1a1a1a
- 次要文字: #666666
- 边框: #e0e0e0
- 强调色: #FF6B35 (龙虾橙)

### 动效
- 页面切换: GSAP smooth transition (1-1.5s, ease: power2.inOut)
- 卡片悬停: scale 放大 + 轻微位移
- 视图切换: 3D 坐标补间动画

### 字体
- 标题: Times New Roman / serif
- 正文: Helvetica Neue / Arial
- 数字/代码: monospace
