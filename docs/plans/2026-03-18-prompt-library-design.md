# AI 提示词库 - 设计文档

**日期**: 2026-03-18
**类型**: 新功能模块
**状态**: 已批准

---

## 1. 概述

为"泥巴猪的实验田"新增一个 AI 提示词库模块，提供提示词浏览、搜索、复制功能。

## 2. 目标

- 帮助用户发现和使用高效提示词
- 提供分类导航和搜索功能
- 支持一键复制到剪贴板
- 预留用户提交入口

## 3. 技术约束

- 纯静态实现，使用 JSON 文件存储数据
- 无后端数据库
- 不改动现有页面

## 4. 数据结构

### 4.1 提示词数据

```typescript
interface Prompt {
  id: string;
  title: string;           // 标题
  content: string;         // 提示词内容
  category: string;       // 分类 ID
  tags: string[];         // 标签
  description: string;    // 简短描述
  author: string;         // 作者
  createdAt: string;      // 创建时间 (ISO)
}
```

### 4.2 分类数据

```typescript
interface Category {
  id: string;
  name: string;
  icon: string;           // Lucide 图标名
  description: string;
}
```

### 4.3 初始分类

| ID | 名称 | 图标 | 描述 |
|----|------|------|------|
| code | 代码开发 | Code | 编程、调试、代码审查 |

| analysis | 数据分析 | BarChart | 数据处理、统计分析 |

## 6. 功能规格

### 6.1 分类浏览

- 侧边栏显示所有分类
- 点击分类筛选提示词
- 高亮当前选中分类
- 显示每个分类的提示词数量

### 6.2 关键词搜索

- 实时过滤（输入即搜索）
- 搜索范围：标题、描述、标签
- 无结果时显示空状态

### 6.3 提示词卡片

- 显示：标题、描述、标签
- 点击复制按钮 → 复制到剪贴板
- 显示复制成功 toast 提示

### 6.4 详情弹窗

- 点击卡片打开弹窗
- 显示完整提示词内容
- 显示分类、标签、作者
- 复制按钮

### 6.5 提交入口

- "提交提示词" 按钮
- 点击 → 打开 GitHub Issue 链接
- Issue 模板包含提示词格式
