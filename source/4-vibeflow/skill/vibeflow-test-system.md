# vibeflow-test-system — 系统测试

## 概述

`vibeflow-test-system` 执行系统级集成测试和 NFR 验证。所有项目都必须执行。

---

## 测试类型

### 1. 集成测试

验证模块间协作，接口对接是否正确。

### 2. E2E 测试

端到端用户流程，验证完整链路是否工作。

### 3. NFR 验证

非功能性需求验证：

| 类别 | 验证内容 |
|------|---------|
| 性能 | 响应时间、并发能力 |
| 安全 | 渗透测试、权限验证 |
| 可用性 | 可用率、灾备切换 |
| 可扩展性 | 水平扩展验证 |

---

## 执行方式

Test-System 和 Test-QA（仅 UI 项目）在 Review 通过后**并行执行**：

```
Review 通过
        ├──▶ Agent: Test-System（所有项目）
        └──▶ Agent: Test-QA（仅 UI 项目）
```

---

## 问题处理

| 严重程度 | 处理方式 |
|---------|---------|
| **严重/重要** | 自动修复后重新验证 |
| **次要/外观** | 与用户确认是否修复 |

---

## 注意事项

- 测试前准备好真实可用的测试数据
- 在隔离环境中执行，避免影响生产
- 记录详细的测试日志用于复现问题
