# vibeflow-ship — 发布

## 概述

`vibeflow-ship` 准备发布产物并执行发布流程。

---

## 发布内容

### 1. 版本管理

- 版本号规范（SemVer）
- 标签打标

### 2. 发布产物

- 构建产物
- 文档更新
- API 文档

### 3. 变更记录

- CHANGELOG 更新
- RELEASE_NOTES 编写

### 4. 发布验证

- Smoke Test
- 健康检查

---

## 产出物

- 版本标签
- PR/MR 合并
- 发布说明

---

## 发布检查清单

- [ ] 所有测试通过
- [ ] 版本号已更新
- [ ] CHANGELOG 已更新
- [ ] 构建产物就绪
- [ ] Smoke Test 通过

---

## 注意事项

- 发布前确保所有质量关卡通过
- 按模板配置执行对应的版本策略
- 记录发布日志便于追溯
