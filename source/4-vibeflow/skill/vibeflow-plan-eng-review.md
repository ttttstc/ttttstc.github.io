# vibeflow-plan-eng-review — 工程视角评审

## 概述

`vibeflow-plan-eng-review` 是工程视角的评审 skill。在 Design 阶段末尾执行，检查技术设计的可行性、架构合理性和代码质量。

---

## 评审维度

### 1. 架构设计

- 整体架构是否合理？
- 模块划分是否清晰？
- 依赖关系是否正确？
- 是否有循环依赖风险？

### 2. 技术选型

- 技术栈选择是否恰当？
- 是否有更好的替代方案？
- 是否符合团队技术能力？

### 3. 数据模型

- 数据模型设计是否合理？
- 是否有性能隐患？
- 扩展性如何？

### 4. API 设计

- RESTful 设计是否规范？
- 是否有更好的接口设计？
- 版本管理策略？

### 5. 安全

- 是否有安全漏洞？
- 敏感数据如何保护？
- 权限控制是否完善？

### 6. 性能

- 关键路径的性能设计？
- 是否有 N+1 查询风险？
- 缓存策略？

### 7. 可维护性

- 代码结构是否清晰？
- 是否有明显的代码坏味道？
- 文档是否完整？

## 注意事项

- 这是技术评审，关注"能不能做"
- 不要讨论"值不值得做"（那是价值评审的事）
- 发现问题要给出具体建议
