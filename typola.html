  1. 安装，打开你的材料。

    从 Releases 下载 Windows 安装版或完整免安装包，打开文档。

  2. 接上你自己的 AI。

    安装并配置 Claude Code 或 OpenCode，在「设置 → AI 执行」检测环境。

  3. 选一个场景，完成一件作品。

    直接对话，或从 SkillHub 选择可用能力。审阅内容，再把成果存为文件。

没有 AI，也能用吗？

可以使用本地 Markdown 编辑与文档功能。AI 与在线资源需要相应环境；本地优先不代表 AI 推理离线，内容如何传输取决于你配置的 Provider。

生成 PPT，需要额外能力吗？

PPT、HTML 等创作场景依赖所选 AI 与可用 Skill；具体格式和质量由执行能力决定。Typola 负责上下文、场景入口与产物处理，不内置模型账号。

导出与安装需要什么？

Windows 应用依赖 WebView2。PDF 导出需要本机 Chrome、Chromium 或 Edge；Word 导出使用内置生成器，无需 Pandoc。请按 Releases 的安装说明操作。

修改如何保持可控？

选区 AI 结果先展示差异，确认后写回，可撤销。整篇检视支持候选稿审阅；应用前应检查全部差异，未逐项表态的片段可能按采纳合并。
